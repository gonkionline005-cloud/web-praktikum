# Личная библиотека

Приложение для учёта книг: статус чтения (хочу прочитать / читаю / прочитано) и заметки к книгам.

## Автор
Татьяна Пержан, группа ФТ24ДР62ПИ1

## Сценарий
Пользователь добавляет книгу, указывает статус чтения, оставляет заметку и находит книги по статусу.

## Стек
React + TypeScript + Vite (позже: Node API, Supabase)

## Версия Node
См. файл `.node-version`

## Запуск
Из корня скачанного проекта:
\`\`\`bash
cd frontend
npm ci
npm run dev
\`\`\`

## Проверка сборки
Остановите dev через Ctrl+C. Выполните в frontend:
\`\`\`bash
npm run build
npm run preview
\`\`\`
