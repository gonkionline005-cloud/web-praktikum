# Личная библиотека

Учебный проект по курсу «Практический курс веб разработки» (React + TypeScript + Node), ПГУ им. Т.Г. Шевченко, физико-технический институт.

Приложение для учёта книг — что читаю сейчас, что хочу прочитать, что уже прочитано, плюс заметки по книгам.

**Автор:** Пержан Татьяна, группа ФТ24ДР62ПИ1

## Сценарий

Пользователь добавляет книгу в список, ставит статус (хочу прочитать / читаю / прочитано), может оставить заметку и находить книги по статусу. Пока это только заглушка экрана, без реальных данных — формы появятся в следующих лабораторных.

## Стек

React, TypeScript, Vite. Node API.

## Версия Node

24.21.0 (см. файл `.node-version`)

## Как запустить

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Откроется на http://localhost:5173

## Проверка сборки

Остановите dev через Ctrl+C, затем в frontend:

```bash
npm run build
npm run preview
```

## Что работает сейчас

Стартовый экран с названием приложения, описанием и заглушкой раздела «Мои книги».

## Текущие ограничения

Форм добавления книг, маршрутизации, авторизации, работы с Supabase и Node API пока нет — появятся потом.
