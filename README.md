# Личная библиотека

Учебный проект по курсу «Практический курс веб разработки» (React + TypeScript + Node), ПГУ им. Т.Г. Шевченко, физико-технический институт.

Приложение для учёта книг — что читаю сейчас, что хочу прочитать, что уже прочитано, плюс заметки по книгам.

**Автор:** Пержан Татьяна, группа ФТ24ДР62ПИ1

## Сценарий

Пользователь просматривает список книг, открывает подробности конкретной книги, переходит к экрану добавления (пока заглушка). Данные пока демонстрационные — хранятся в коде, без базы. Формы для реального добавления/редактирования появятся в следующих лабораторных.

## Стек

React, TypeScript, Vite. Node API.

## Версия Node

24.21.0 (см. файл `.node-version`)

## Как запустить

Из корня скачанного проекта:

```bash
cd frontend
npm ci
npm run dev
```

Откроется на http://localhost:5173

## Проверка сборки

Остановите dev через Ctrl+C, затем в frontend:

```bash
npm run build
npm run preview
```

## Возможности (ЛР 3)
- Просмотр списка книг и карточки книги
- Добавление книги (форма с проверкой)
- Редактирование книги той же формой
- Удаление книги с подтверждением
- Фильтр списка по статусу чтения со сбросом

## Страницы приложения

- `/` — перенаправляет на список книг
- `/books` — список всех книг
- `/books/:id` — подробности конкретной книги (например `/books/b1`)
- `/books/new` — заглушка добавления книги 
- любой другой адрес — страница "не найдено"

## Текущие ограничения

Данные хранятся только в памяти приложения. После обновления страницы
возвращаются демонстрационные книги из ЛР 2.

## Справочник жанров (ЛР 4)

Жанры книг загружаются по HTTP из файла `frontend/public/demo/genres.json` (в приложении он доступен по адресу `/demo/genres.json`, запрос виден в Network). Загрузка вынесена в сервис `src/services/genres.ts`, который проверяет `response.ok` и структуру JSON (массив объектов с уникальными `id` и непустым `name`). Состояниями запроса управляет хук `src/hooks/useGenres.ts`: загрузка, ошибка, пустой справочник и кнопка «Повторить». При уходе со страницы запрос отменяется через `AbortController`.

В форме добавления и редактирования книги жанр выбирается из загруженного списка. Пока справочник не загружен или жанр не выбран, сохранить книгу нельзя. Повторная загрузка не стирает уже введённые поля.

В книге хранится `id` жанра (например `novel`), а на экране показывается его название («Роман»).

Основные записи по-прежнему хранятся только в памяти приложения: после обновления страницы возвращаются демонстрационные книги.
