# Прогресс

## ЛР 1 — Старт проекта
Создан проект React + TypeScript + Vite в frontend/. Реализован начальный экран темы «Личная библиотека» (заголовок, описание, заглушка списка книг). Проверка типов и сборка (`npm run build`) проходят успешно. Проект опубликован в Git-репозитории.

## ЛР 2 — Страницы и навигация
Добавлен React Router: список книг, страница подробностей по id, заглушка создания книги, страница неизвестного адреса. Данные (5 демонстрационных книг) вынесены в типизированный массив `src/data/books.ts`. Создан общий layout с навигацией (`src/app/AppLayout.tsx`). Проверены сценарии: пустой список, отсутствующая запись, неизвестный путь, прямое открытие карточки, узкий экран, навигация с клавиатуры и кнопками браузера. Сборка и preview проходят без ошибок.
