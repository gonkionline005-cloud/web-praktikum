## ЛР 4 — Справочник жанров по HTTP

Справочник жанров лежит в `frontend/public/demo/genres.json` и запрашивается через `fetch` в `src/services/genres.ts` с проверкой `response.ok`, структуры ответа и уникальности `id`. Хук `src/hooks/useGenres.ts` даёт состояния loading, error, success. Форма `BookForm` использует `select` вместо свободного ввода, блокирует сохранение без выбранного жанра, кнопка «Повторить» сохраняет черновик.

Шаги проверки: создание и редактирование с выбором жанра; медленная сеть; Offline → Online и «Повторить» без потери названия; неверный путь к файлу; пустой массив `[]`; объект вместо массива, числовой `id`, повторяющийся `id`; уход со страницы во время загрузки; `npm run build` и `npm run preview`.

Коммит: 40be66d Lab 4: load reference data over HTTP

## ЛР 5. Схема данных и справочник в Supabase

Таблицы: `genres` (публичный справочник, PK `id`, чтение для anon и authenticated), `books` (личные записи, PK `id`, `owner_id` → `auth.users`, `genre_id` → `genres.id`; RLS включён, прав для клиентских ролей нет).

Порядок применения: 1) `supabase/migrations/202610250001_initial_schema.sql`, 2) `supabase/seed.sql` в SQL Editor.

Проверка: запрос к Supabase в Network; пустой справочник и восстановление seed с кнопкой «Обновить справочник»; запрет insert в `genres` и select из `books` из браузера (ошибка 401 / 42501); CRUD и фильтр ЛР 3; `npm run build` и `npm run preview`.

Коммит: 221386a Lab 5: add Supabase schema and reference data
